## 기말공부요약
 웹 이론 및 트렌드
 V8 엔진 구성: Parser(AST 생성) → Ignition(바이트코드 인터프리터) → TurboFan(최적화 JIT 컴파일러).

 WebAssembly: 기계어 수준으로 최적화 불필요, 고성능 처리에 적합.
 세션 vs 토큰(JWT): 세션은 서버 저장(보안 유리, 확장성 낮음), 토큰은 클라이언트 저장(확장성 높음, 탈취 위험).
 
 Quarkus & 백엔드
 Quarkus: 빌드 타임 자동 생성, CDI(@Inject)를 통한 의존성 관리로 런타임 오버헤드 최소화.

 Active Record: PanacheEntity 상속으로 별도 Repository 없이 엔티티 내에서 DB 제어 가능.
 
 파일 처리: 가벼운 데이터는 DB, 무거운 미디어는 S3/CDN 분리 저장(비용 및 성능 최적화)

보안 및 인증 (중요)
비밀번호 암호화: 평문 저장 절대 금지. 단방향 해시(SHA-256, bcrypt) 사용 필수.

프론트/백엔드 연동:
프론트: crypto.subtle.digest로 비동기 해시 변환 후 전송.

백엔드: 303 See Other (PRG 패턴)로 리다이렉트 처리, 세션 체크로 '강제 브라우징' 차단.

비밀번호 변경: 현재/새 비밀번호 모두 해시화하여 전송, 서버에서 일치 확인 후 업데이트.

핵심 UX 및 로직 구현
비동기 UX: setTimeout으로 성공 메시지(Toast)를 3.5초간 노출한 후 페이지 이동(비동기 로직).

라우팅: @QueryParam으로 전달된 next 파라미터에 따라 이동 경로 동적 분기.

파일 업로드: multipart/form-data 사용 필수, UUID로 파일명 중복 방지.
